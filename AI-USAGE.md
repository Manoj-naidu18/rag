# AI usage

I used an AI coding assistant to help outline the file structure, draft small Python functions, and review the ten test questions.

I supplied the policy manual and amendment as the only policy sources. I checked the date rules, clause numbers, refusal behavior, and test outputs against those files. The assistant does not call an AI service at runtime; it uses Python's standard library and a small set of explicit policy topics.

The final code was kept deliberately direct so another developer can explain each answer path during review.
